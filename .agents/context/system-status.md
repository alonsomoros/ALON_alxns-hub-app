# Estado del sistema

Actualizado: 2026-11-11. Este archivo solo resume el estado; el detalle vive en `Issues/README.md` (notas `REQ-NNN`) y en `docs/`.

- **Fase:** foundation / dashboard personal simplificado.
- **Implementado:** splash breve, Inicio con fecha del sistema, cita con fallback, tarjeta Raspberry (métricas reales cada 60 s si hay API; datos de ejemplo si no), logros, servicios como logos clicables con fallback, vista de retos (alta, edición, archivo, historial), vista de enlaces (alta, borrado, reordenación por arrastre y teclado, máximo 10) y navegación simple.
- **Implementado parcialmente (`REQ-018`):** API de persistencia SQLite (`server/index.js`) con `GET /health`, `GET /api/state` y `PUT /api/state` con versión optimista; adaptador `src/infrastructure/persistence.ts` con timeout de 1.5 s y caché en `localStorage`; imagen Docker y Compose con volumen y reinicio automático. Solo se activa con `VITE_PERSISTENCE_API_URL`; sin ella, retos y enlaces viven en memoria con datos de prototipo.
- **Desplegado (`REQ-011`):** `GET /api/pi/metrics` (`server/metrics.js`) agrega Prometheus y un docker-socket-proxy de solo lectura; la PWA sondea cada 60 s (`usePiMetrics`) con estados `loading`/`online`/`degraded`/`stale`/`offline`. Verificado en la Pi frente a `vcgencmd`, `free`, `df` y `docker ps`; el `docker-proxy` no publica puertos y rechaza escrituras (403).
- **Ajustes (`REQ-003`):** pantalla de Ajustes (engranaje en la cabecera) con seis temas, vista de stats (barras, anillos, medidores), orden y visibilidad de las tarjetas de Inicio e intervalo de refresco (30, 60, 120 s). Las preferencias se validan con `parsePreferences`, se guardan en `localStorage` y se sincronizan con la API dentro de `PUT /api/state`; los colores salen de variables de tema (`src/themes.ts`). `npm test` ejecuta pruebas `node:test` de los módulos puros.
- **Producción:** PWA en `https://alxns-hub.vercel.app`; API en la Pi por `tailscale serve` (`https://raspberrypi.tail6f4cba.ts.net`, solo tailnet). Cada dispositivo necesita Tailscale. La tarjeta Raspberry tiene un desplegable «Ver detalle» con los contenedores.
- **Pendiente:** backups del volumen con retención, ACL de Tailscale, igualar `ALLOWED_ORIGINS` del `.env` de la Pi, adaptadores de Grafana y healthchecks, adaptador de cita con timeout, runner de tests (`REQ-020`) y E2E desde dos dispositivos.
